# Roadmap

Potential post-1.0 extensions, each requiring its own validation:

- native PLINK BED and PGEN readers through optional audited dependencies;
- mixed-model score tests for relatedness and structured cohorts;
- cross-fitted inference that rotates discovery and inference partitions;
- genotype-model encodings beyond additive dosage products;
- LD-aware candidate grouping and locus-level summaries;
- calibrated permutation workflows that repeat the complete selection process;
- deterministic parallel candidate evaluation;
- documented distributed coverage matrices for large candidate universes;
- plugin interfaces for annotation databases without bundling licensed data.

Roadmap items are not current capabilities and should not be described as implemented.
